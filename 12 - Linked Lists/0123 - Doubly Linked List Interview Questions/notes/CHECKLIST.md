# Doubly Linked List — Interview / LeetCode Exercises

Source: Java DSA + LeetCode (Scott Barrett, Udemy) — exact lecture names.

- [ ] Palindrome Checker — walk from both ends inward using head/tail pointers (DLL makes this natural, unlike singly linked list)
- [ ] Reverse
- [ ] Partition List
- [ ] Reverse Between
- [ ] Swap Nodes in Pairs

The last three mirror the singly-linked-list versions in `0121` — solve those first, then redo here and compare: which parts get simpler with a `prev` pointer, which don't change at all. That comparison is itself good interview material ("when would you pick DLL over LL").
