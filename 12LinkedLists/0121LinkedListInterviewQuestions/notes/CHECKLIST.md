# Linked List — Interview / LeetCode Exercises

Source: Java DSA + LeetCode (Scott Barrett, Udemy) — exact lecture names from the course curriculum.

- [ ] Find Middle Node — slow/fast pointer, see `00000 - REVISION HUB/CHEATSHEETS/LinkedList.md`
- [ ] Has Loop — Floyd's cycle detection
- [ ] Find Kth Node From End — single pass, two pointers offset by K
- [ ] Remove Duplicates — from an unsorted linked list (needs a HashSet — ties into your existing 0107/0112 hashing work)
- [ ] Binary to Decimal — treat the list as binary digits, accumulate value
- [ ] Partition List — rearrange around a pivot value (like quicksort partition, but on a list)
- [ ] Reverse Between — reverse only a sub-section [left, right] of the list
- [ ] Swap Nodes in Pairs — reverse adjacent pairs

Solve each in `code/`, one file per problem, in both Java and Kotlin once you're comfortable — this is the highest-yield linked-list interview set, asked constantly.
