# Progress Tracker

Log every revision pass here. This is what makes recall "over time" actually work — without a log you re-revise whatever feels familiar and avoid your weak spots.

## How to use
1. Pick a topic from `INDEX.md`.
2. Close the notes. Try to explain the approach out loud + write the code from memory.
3. Compare against the saved file. Update the row below: bump **Confidence**, set **Last Revised** to today, and set **Next Review** using the spacing rule.

**Confidence scale:** 1 = barely remember it exists · 2 = remember approach, fumble code · 3 = can code it with minor hints · 4 = code it clean in one pass · 5 = could explain + code + handle follow-ups in an interview.

**Spacing rule (simple version of spaced repetition):** Confidence 1-2 → review in 2 days. Confidence 3 → review in 5 days. Confidence 4 → review in 12 days. Confidence 5 → review in 30 days. If a review fails (confidence drops), reset to the 2-day bucket.
